# 쿠파스 실상품 합성 런북 (사용컷 2컷 예약 발행)

> 빵찌 쿠파스 큐의 각 상품에 **링크에 걸린 진짜 상품**을 사용컷 2컷으로 합성해 넣고,
> 크론이 하루 3회 1건씩 **자동 예약 발행**한다. 이 문서가 재현·이어가기 단일 절차.
> 규격 원문은 `prd-쿠파스.md`(§2·§7).

## 원칙 (왜 이렇게 하나)
- 사진 2컷은 **반드시 링크 상품**이어야 한다(어필리에이트).
- git에 저장돼 있던 `ads-partners` **짧은 URL은 만료 시 "오늘의 쿠팡 특가" 배너**로 폴백 → 쓰면 안 됨.
- **검색 API `productImage` 긴 URL = 진짜 상품 사진.** 이걸 매번 새로 받아 쓴다.
- 배경은 사용자가 준 주방사진을 **복제하지 말고 무드만**(따뜻한 우드+화이트 한국 가정), **매번 다른 장면**.
- 구도 깔끔. **손(사람) 넣으면 NSFW 오판·멈춤이 잦아** A컷도 "사람 없음" 제품 장면으로 통일.
- 이미지와 **링크(딥링크)는 같은 상품으로 일치**시킨다.

## 발행(예약) 구조
- 큐 = `queue.json` (FIFO). 크론 `coupas-daily.yml`이 **07:00 / 20:00 / 23:00 KST 하루 3회, 맨 앞 1건씩** 발행 후 큐에서 제거.
- 가드(`publish_from_queue.py`): **사용컷 2장 미달 / `needs_ai_images` 플래그** 항목은 건너뜀 → 1장짜리·미교정은 절대 안 나감.
- 새 상품을 `build_queue.py`로 담으면 `needs_ai_images:true`가 붙는다 → **발행 전 반드시 실상품 2컷 주입**해 플래그 해제.

## 절차 (전량/증분 공통)
1. **실상품·딥링크 수집**: `gh workflow run coupas-fetch.yml` → `fetch_products.py`가 큐 상품명 재검색 →
   `products.json = {상품명:{img(긴 URL), link(딥링크)}}` 커밋. (레이트리밋 재시도 내장, 멱등)
2. **세션에서 합성**(GitHub Actions엔 힉스필드 MCP 없음 → 세션 전용):
   - `media_import_url(img)` → media_id (URL 아님).
   - `generate_image_batch`(model **nano_banana_pro**, `medias:[{value:media_id, role:image}]`).
     프롬프트: "reference 상품 그대로 유지 + 판촉텍스트 제거 + **매번 다른** 따뜻한 한국 가정 장면 + no people".
     배경은 12종 풀 로테이션(제품 index로 A/B 다르게).
   - 실패(NSFW/멈춤)는 같은 프롬프트로 재시도. 5장 동시 NSFW면 대개 일시 오류 → 재시도로 통과.
3. **주입**: `set_images.py <index> <u1> <u2>` 또는 상품명 기준 `apply_product.py /tmp/applied.json`
   (`{상품명:{images:[u1,u2], link}}`) → images 교체 + reply 링크 치환 + 플래그 해제.
4. **저장**: `git add queue.json && git commit && git pull --rebase && git push`.
   (크론 봇이 큐 소비 커밋을 올리므로 push 전 `git pull --rebase` 필수. `git config pull.rebase true` 해둠.)

## 진행 상태 (이어가기용)
- 큐 상품 총 124종. **교정 완료 = `needs_ai_images` 없는 항목** = `queue.json`이 단일 기준.
- 현재까지 53건 완료 / 70건 보류(2026-08-13). 남은 것은 위 절차 2~4 반복.
- 남은 대상 뽑기: `python set_images.py --status` 또는
  `python -c "import json,re;d=json.load(open('queue.json'));print([re.search(r\"🔽'(.+?)' 정보는\",it['reply']).group(1) for it in d['items'] if it.get('needs_ai_images')])"`

## 도구 요약
- `fetch_products.py` / `coupas-fetch.yml` — 실상품 이미지·딥링크 수집(products.json).
- `apply_product.py` — 상품명 기준 이미지2+링크 주입(플래그 해제).
- `set_images.py` — index 기준 주입 / `--status` / `--batch`.
- `publish_from_queue.py` / `coupas-daily.yml` — 예약 발행(2장 캐러셀, 미교정 건너뜀).
- `coupas-delete.yml` — 게시물 삭제(단, Threads API가 삭제 미지원이라 실패 → 앱에서 수동 삭제).
